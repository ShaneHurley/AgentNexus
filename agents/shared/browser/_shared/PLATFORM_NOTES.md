# Platform Notes

Use one host-neutral pack; do not create per-product folders. Connected storage does not imply write authority.

| Host | Stable instructions surface | Attachments / knowledge | Research / browse | Execution / writes | Pack notes |
|---|---|---|---|---|---|
| Gemini | Gem/custom instructions where available | Files and connected sources vary | Deep Research availability varies | Do not assume writes | Keep core short; review research plan |
| ChatGPT | Custom instructions/projects vary | Files and project knowledge vary | Search/deep research varies | Connectors are not authority | Paste one role per task |
| Claude | Projects/custom instructions vary | Project files; chat sharing varies | Web/research varies | Tool access varies | Reattach packet in a new chat |
| GitHub Copilot | Repository instructions and custom agents | Repository context varies | Product-dependent | Some coding surfaces execute | Distinguish chat from agent execution |
| Microsoft Copilot | Organization/user instructions vary | Microsoft 365 grounding varies | Web grounding varies | Tenant controls apply | Enterprise policy precedes prompt |
| Cursor web/cloud | Rules/skills and task prompt | Repo attachment/clone varies | Search depends on environment | Cloud agents may clone, edit, test, and open PRs | Execution-capable only when visibly enabled |
| Perplexity | Space/project instructions vary | Upload and project limits vary | Research is a core surface | Usually research-oriented | Verify source dates and file limits |
| Grok | Conversation/project features vary | Attachment support varies | Browse varies | Do not assume writes | Reattach instructions for high-stakes new threads |

Prefer short persistent instructions containing the core contract. Load exactly one role block per task. Verify current plan, region, retention, connector, and execution behavior before use.
