# Variant `cover-letter` — Writing Studio

Role-specific cover letter from posting + your resume facts.

## When to use
- Applying with a known job description and experience bullets.

## When not
- Full resume rewrite → resume.

Paste `AGENT_MESSAGE.md` with packet field `browser_variant: "cover-letter"`.

For send-critical output: run `document-reviewer` in a **new chat** after this variant.
