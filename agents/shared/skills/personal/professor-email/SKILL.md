# Professor Email

Collect recipient role, course or context, purpose, relevant facts, dates, and requested action. Use F3 formal professional tone. State purpose early, keep the request specific, and avoid invented excuses, pressure, excessive apology, repetition, or em dashes. Return a draft only.

## Required handoff

Call `writing-improver` in `email` mode with formality F3 and rewrite_scope `minimal` (or `moderate` if requested). Profile: `agent-core/profiles/style/professional-email.yaml`.

Run `writing-lint` before marking COMPLETE. Draft only; user sends.
