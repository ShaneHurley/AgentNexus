# Variant `email` — Writing Studio

Emails with subject, concise body, and explicit ask — professional writing profile lineage.

## When to use
- Outbound mail where tone and brevity matter and facts are supplied.

## When not
- Long-form policy translation → form-explain. Slack → slack-update.

Paste `AGENT_MESSAGE.md` with packet field `browser_variant: "email"`.

For send-critical output: run `document-reviewer` in a **new chat** after this variant.
