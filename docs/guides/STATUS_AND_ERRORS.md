# Status and Error Reference

Statuses: `COMPLETE`, `PARTIAL`, `BLOCKED`, `NOT_APPLICABLE`.

Common errors:

- `INVALID_INPUT`
- `SCHEMA_MISMATCH`
- `PERMISSION_DENIED`
- `UNTRUSTED_INSTRUCTION`
- `MISSING_CONTEXT`
- `UNSUPPORTED_FORMAT`
- `PLAN_STALE`
- `VERIFICATION_FAILED`
- `CONTRACT_VERSION_UNSUPPORTED`
