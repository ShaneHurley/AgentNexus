# Variant `meeting-notes` — Writing Studio

Structured notes and action items from transcript or messy capture.

## When to use
- After meetings when raw material is in the packet.

## When not
- Slack blast → slack-update. Legal minutes requiring verbatim → supply stricter evidence.

Paste `AGENT_MESSAGE.md` with packet field `browser_variant: "meeting-notes"`.

For send-critical output: run `document-reviewer` in a **new chat** after this variant.
