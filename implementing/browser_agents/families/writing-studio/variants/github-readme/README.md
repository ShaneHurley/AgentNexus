# Variant `github-readme` — Writing Studio

Developer-facing README from repo tabs or pasted tree.

## When to use
- Open-source or internal repo documentation in GitHub flavor markdown.

## When not
- Issue filing → github-issue. Deep spec → tech-doc.

Paste `AGENT_MESSAGE.md` with packet field `browser_variant: "github-readme"`.

For send-critical output: run `document-reviewer` in a **new chat** after this variant.
