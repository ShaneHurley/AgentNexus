# Glean plugin vs personal skills

Do **not** fork Glean skills into this catalog. Use the Cursor Glean plugin when MCP is available. Author student-local skills only for school, calendar, and private career data Glean cannot see.

## Disposition

| Glean skill | Disposition |
|-------------|-------------|
| `using-glean`, `search`, `glean_run` | Reuse via `/plan-prep` / MCP; do not duplicate |
| `plan-prep` | UF `/plan-prep` only |
| `using-glean-code`, `codebase-context`, `similar-code`, `find-examples`, `verify-rfc` | Engineering; `/researcher` + Glean code |
| `code-owners`, `find-expert`, `stakeholders` | Reuse Glean; career skills never invent org charts |
| `meeting-prep`, `catch-up`, `onboarding`, `project-awareness`, `project-handoff` | Reuse for enterprise; `interview-prep` is not a copy |
| `using-glean-productivity` | Pattern donor for accomplishments (did≠viewed; cite sources) |
| `skill-creation-guide` | Mandatory authoring checklist for every new `SKILL.md` |

## Patterns stolen (not tool encyclopedias)

- Triggers in YAML `description` (~200 words)
- Progressive disclosure (`references/`)
- Freshness / authority vetting; “nothing found” is valid
- Honesty degrade when sources missing (`GLEAN_UNAVAILABLE` / Limited Research style)
- Activity shape: Highlights → By theme → Collaborations → In progress
- Worth-it gate: recurrence / automation / value / duplication

## Freshness bands (locked)

`<6 months` include with confidence; `6–12` with staleness note; `12+` exclude unless no alternative (strong warning).
