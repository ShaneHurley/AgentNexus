# Promotion gates (SPEC §15)

Reconsider deferred orchestrators only when gates pass.

| Gate | Promote when |
|------|----------------|
| Skill → browser role | Portable draft reuse is frequent and soft-only is enough |
| Skill → shared delegate | Isolated long-form context, distinct tools, or typed packets needed by orchestrators |
| Family → domain orchestrator | Persistent state + cross-skill coordination + measured value |
| Domain → UF IDE agent | Direct invocation so frequent that discovery is a usability problem |

A convenience name is not enough for a seventh user-facing IDE agent.

**Default after Phase 5 review:** remain skills. Writing stays on-demand `writing-improver`.
