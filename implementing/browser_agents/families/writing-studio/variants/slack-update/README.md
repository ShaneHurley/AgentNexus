# Variant `slack-update` — Writing Studio

Team Slack updates with lead sentence and explicit next step.

## When to use
- Quick internal comms with supplied status facts.

## When not
- Formal external email → email. Meeting record → meeting-notes.

Paste `AGENT_MESSAGE.md` with packet field `browser_variant: "slack-update"`.

For send-critical output: run `document-reviewer` in a **new chat** after this variant.
