# Variant `github-issue` — Writing Studio

Bug report or feature request formatted for GitHub issues.

## When to use
- Turning notes or tabs into an issue body.

## When not
- PR description → use github-readme/tech-doc patterns or packet objective.

Paste `AGENT_MESSAGE.md` with packet field `browser_variant: "github-issue"`.

For send-critical output: run `document-reviewer` in a **new chat** after this variant.
