# Variant `form-explain` — Writing Studio

Forms and policy text explained in plain language with locators — ex bureaucracy-translator.

## When to use
- User needs to understand what a form or policy asks, not courtroom judgment.

## When not
- Compliance verdict → document-reviewer/policy-compliance. Raw field extract → research-desk/field-extract.

Paste `AGENT_MESSAGE.md` with packet field `browser_variant: "form-explain"`.

For send-critical output: run `document-reviewer` in a **new chat** after this variant.
