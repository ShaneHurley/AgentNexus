# Variant `policy-compliance` — Document Reviewer

**Compliance judgment** — artifact vs policy/rule text supplied in the packet or attachments.

**Focus:** must/shall vs should/may, coverage map to rule clauses, owners and dates, conflicts between artifact and policy.

**Distinction:** `research-desk/obligation-register` extracts obligations **without** a ship verdict. This variant emits `VERDICT` + `FINDINGS`.

**Paste:** `AGENT_MESSAGE.md` with `browser_variant: policy-compliance` and attach rule corpus + draft under review.

**Not legal advice** — flag gaps; qualified humans decide institutional compliance.
