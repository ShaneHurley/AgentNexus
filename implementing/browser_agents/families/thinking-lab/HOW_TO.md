# How to use Thinking Lab

| Lens | `browser_variant` |
|------|-------------------|
| Challenge an idea | `idea-stress-test` |
| Tail / cascade failure | `cascade-risk` |
| Imagine failure first | `pre-mortem` |
| One-way vs two-way doors | `decision-reversibility` |

Paste the variant in a **new chat** with the proposal/plan as evidence. This family does not implement or book anything.

**Legacy:** `friction` → `idea-stress-test`; `risk-audit` → `cascade-risk`.
