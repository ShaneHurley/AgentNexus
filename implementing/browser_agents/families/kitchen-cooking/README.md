# Kitchen Companion

Pantry-first cooking and meal planning for browser sessions. Allergies and dietary restrictions are **hard constraints**, not soft preferences (see ai_profile_kitchen_helper.md).

## Variants
Split by outcome so prompts stay small: brainstorm vs full recipe vs weekly plan vs allergen scan vs vibe/leftover/batch/equipment paths.

## Safety
The agent flags conflicts and unknowns; it does not provide medical or allergen safety certification.
