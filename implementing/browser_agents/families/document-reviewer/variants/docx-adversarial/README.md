# Variant `docx-adversarial` — Document Reviewer

**Default long-form walk** — same procedure as family main. Use for Word (.docx), Google Doc exports, wiki paste, Notion export, and other editable long-form prose.

**Focus:** structure, internal consistency, claims vs evidence in the doc, clarity, acceptance mapping.

**Paste:** `AGENT_MESSAGE.md` with `browser_variant: docx-adversarial` (optional — main paste is equivalent).

**Not for:** PDF-only artifacts with OCR risk → `pdf-adversarial`. Extract-only → `research-desk/assemble-given`.
