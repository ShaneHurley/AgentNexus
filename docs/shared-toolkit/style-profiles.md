# Style Profiles

## F1: Polished conversational

Use for classmates, teammates, and familiar peers. Keep language natural, warm, and respectful.

## F2: Professional collaborative

Use for coworkers, engineers, project partners, and teaching assistants. Be direct, cooperative, and technically precise.

## F3: Formal professional

Use for professors, advisors, managers, recruiters, and unfamiliar professionals. Use structured requests, careful qualification, and concise professional closings.

## F4: Formal technical

Use for future contributors, reviewers, and auditors. Explain behavior, interfaces, assumptions, limits, and verification with source-aligned terminology.

All levels prohibit em dashes, repeated ideas, fabricated context, inflated language, and inconsistent vocabulary.
