# Variant `personal-project` — Writing Studio

Blog posts, personal statements, and portfolio narrative from your supplied facts.

## When to use
- Non-corporate writing where you control the message.

## When not
- Job application pack → resume + cover-letter. Marketing claims → ads-marketing.

Paste `AGENT_MESSAGE.md` with packet field `browser_variant: "personal-project"`.

For send-critical output: run `document-reviewer` in a **new chat** after this variant.
