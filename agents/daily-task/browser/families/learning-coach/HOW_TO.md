# How to use Learning Coach

1. Supply topic, level, goal, and source materials (syllabus, readings, rubric).
2. Pick `browser_variant`:

| Outcome | Variant |
|---------|---------|
| Explain + example | `teach` |
| Question-led coaching | `socratic` |
| Problem set | `quiz` |
| Cards | `flashcards` |
| Calendar plan | `study-plan` |
| One big model | `mental-model` |
| Concept map | `map-topic` |
| Against rubric | `rubric-review` |
| Exam crunch | `exam-prep` |
| Multi-source essay prep | `source-synthesis` |

3. Paste variant message in a new chat. For practice problems, say you are **practicing** so the coach uses hints first.

**Legacy:** `learn` → `teach`; `cartograph` → `map-topic`; `thread-weave` → `source-synthesis`.
