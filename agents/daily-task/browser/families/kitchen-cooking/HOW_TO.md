# How to use Kitchen Companion

1. List pantry/fridge, **allergies/restrictions as fixed constraints**, equipment, time, servings in the task packet.
2. Set `browser_variant`:

| Goal | Variant |
|------|---------|
| Quick ideas | `brainstorm` |
| One recipe | `recipe` |
| Week plan + shop list | `meal-plan` |
| Check menu/ingredients vs allergies | `allergy-diet-scan` |
| Mood/cuisine match | `vibe-cook` |
| Use leftovers | `leftover-rescue` |
| Prep ahead | `batch-prep` |
| One pan / limited gear | `equipment-limited` |

3. Paste variant `AGENT_MESSAGE.md` into a new chat. Confirm allergen data on packaging before serving.

**Legacy:** `kitchen-recipe` / `diet-scan` → `recipe` / `allergy-diet-scan`.
