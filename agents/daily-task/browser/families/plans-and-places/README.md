# Plans & Places

Trip and event logistics for browser paste workflows: itineraries, packing, errands, run-of-show, dietary cross-checks, discovery, weather contingencies, group constraints, and budget tradeoffs.

## Thought process
- **Anchor first** — dates, places, and fixed constraints beat inspirational filler.
- **Evidence-bound** — live hours, prices, and allergens stay UNKNOWN until sourced.
- **Safety over completeness** — SAFETY_FLAGS and VERIFY_BEFORE_GO when stakes are travel- or allergy-related.

## Variants
Each variant is a focused paste so context stays small. Main agent classifies when you omit `browser_variant`.
