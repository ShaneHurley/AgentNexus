# Lovable.dev & Vercel v0: AgentNexus UI Prototyping Guide

This guide covers using **Lovable.dev** and **Vercel v0** alongside **Bolt.new** as zero-cost web UI builders for **AgentNexus**.

---

## 1. Role in the Free-Tier Pipeline

When `Bolt.new` daily free tokens are exhausted, rotate immediately to:
- **Lovable.dev** (5 free messages/day for full-stack React + Supabase apps)
- **Vercel v0** (Free monthly credits for React + Tailwind + shadcn/ui components)

Both accept output specifications generated by AgentNexus's `visualization-specifier` skill (`agents/shared/skills/shared/visualization-specifier/`).

---

## 2. Workflow

1. Run `visualization-specifier` to produce a structured UI specification.
2. Paste the specification along with the prompt in [`ui_prompt_pack.md`](./ui_prompt_pack.md) into Lovable.dev or v0.dev.
3. Export the generated React/Tailwind code into `gui/agent_dashboard/web/`.
